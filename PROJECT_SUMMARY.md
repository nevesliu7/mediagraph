
# MediaGraph Project Summary

MediaGraph is a Streamlit-based media intelligence prototype that models Chinese and American film ecosystems as a connected graph. It combines curated demo data, NetworkX graph metrics, Plotly visualizations, and rule-based recommendation logic to explore creative networks, bridge creators, genre opportunity, award pathways, and director-actor fit.

Resume bullet:
Built MediaGraph, a hybrid Vercel-ready bubble graph + Streamlit analyst prototype that maps Chinese and American film ecosystems, scores director-actor creative fit, and surfaces cross-market talent and award pathways through explainable network analysis.


Hybrid web + Streamlit delivery:
- `web/` provides a Vercel-ready bubble graph experience
- `app.py` provides the analyst-focused Streamlit view
